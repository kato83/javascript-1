# 冬休み課題 — Deno自由制作課題 (work2)

## 課題の趣旨

これまでの授業で学んだJavaScriptの基礎知識を活用し、**Denoランタイム**を使って**自由にアプリケーションを制作**してください。

work1では決められた関数を実装する課題でしたが、work2では**あなたのアイデアと創意工夫**を最大限に発揮できる自由制作課題です。

> [!NOTE]
> ## AI利用について
> 今回の課題では課題1（ `work1/` ）とは異なり **ChatGPT等の生成AIツールの利用を許可** します。
> ただし、AIを使用した場合は提出時にその旨を明記してください。
> 重要なのは「何を作ったか」「どんな工夫をしたか」です。

- **創造性とアイデア力**の発揮
- **Denoの実践的な活用**能力の習得

## 技術参考資料

### Deno公式ドキュメント
- [Deno Manual](https://docs.deno.com/runtime/manual/)
- [Deno Standard Library](https://jsr.io/@std)

### よく使用される機能
```javascript
// 読み込み https://docs.deno.com/api/deno/~/Deno.readTextFile
// 書き込み https://docs.deno.com/api/deno/~/Deno.writeTextFile
// 代替の読み書き方法 https://docs.deno.com/api/node/fs/
const text = await Deno.readTextFile("./data.txt");
await Deno.writeTextFile("./output.txt", "Hello World");

// HTTP サーバー https://docs.deno.com/runtime/fundamentals/http_server/
// その他参考: https://qiita.com/aKuad/items/6ea37f01db7eb8d2ad4e
import { serve } from "jsr:@std/http/server";
serve((req) => new Response("Hello World!"));

// 外部API呼び出し https://docs.deno.com/api/web/~/fetch
const response = await fetch("https://api.example.com/data");
const data = await response.json();

// コマンドライン引数 https://docs.deno.com/api/deno/~/Deno.args
console.log(Deno.args); // ["arg1", "arg2"]
```

### 推奨JSRパッケージ
- `@std/http` - HTTPサーバー・クライアント
- `@std/fs` - ファイルシステム操作
- `@std/path` - パス操作
- `@std/csv` - CSV処理
- `@std/datetime` - 日時処理
